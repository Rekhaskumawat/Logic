# Scenario Based Questions

### Question 1 (program77_1)

```
Description : Calculates total hospital bill including:

                Consultation fee
                Medicine bill
                Room charges per day (Normal / ICU)

                If insured:

                Covers 70% of bill OR ₹50,000 (whichever is lower)
```
---
### Question 2 (program77_2)

```
Description :  Fare depends on:

                Distance
                Class (Sleeper / 3AC / 2AC)
                Tatkal booking (< 24 hrs -> +30%)
                Senior citizen (age >= 60 -> −40%)
```
---

### Question 3 (program77_3)

```
Description :  User enters usage: calls (min), data (GB), SMS (count). App suggests the cheapest plan among 4 plans.

                    Input: mins, gb, sms
                    Output: recommendedPlan, totalCost

                    Twist: if usage exceeds plan limits, add per-unit extra
```
---

### Question 4 (program77_4)

```
Description : Slabs + fixed meter charge. If paid after due date, add 2% penalty per week late (max 10%).

                    Input: units, weeksLate
                    Output: billAmount
```
---

### Question 5 (program77_5)

```
Description :  Seats have different prices per row. User tries booking multiple seats; reject if already booked. If group size ≥ 6, give 10% discount.

                    Input: rows, cols, bookedSeatList, requestedSeatList
                    Output: success/fail + total cost + remaining seats
```
