
# Scenario Based Question

### Question 1 (program76_1)

```
Description : A ride-hailing app calculates fare based on:

    Distance travelled
        Whether it is peak hour
        
        Fare rules:
            Base fare = ₹50
            First 10 km -> ₹12/km
            After 10 km -> ₹15/km
            Peak hour -> +20% surcharge
```

### Question 5 (program76_5)

```
Description : A phone OS shows different battery warnings. The user wants a program that prints the correct battery status.

    Rules:
        Battery ≤ 5% → Critical
        Battery ≤ 15% → Low
        Otherwise → Normal

    Input:
        Battery percentage (integer)
    
    Validations:
        Input should be between 0 to 100

    Expected Output:

    Battery Percentage: <value>
    Status: <Critical/Low/Normal>
```
